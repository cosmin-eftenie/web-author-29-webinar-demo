# Web Author 29 webinar demo

Demo content for "What's New in Oxygen XML Web Author 29".

- `images/` - stored with **Git LFS** (see `.gitattributes`); the repository only keeps pointers.
- `topics/`, `webinar-wa29.ditamap` - regular Git (editable in Web Author).
- `config/app-settings.xml` - generic XML with no framework, opens in Text mode.

Open `webinar-wa29.ditamap` or `topics/git-lfs-images.dita` in Web Author with the GitHub connector.
